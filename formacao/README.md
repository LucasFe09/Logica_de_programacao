# Formação Code & CodeVibe

Livro interativo em português com 10 capítulos, revisões de múltipla escolha, exercícios de código no VS Code e prova final corrigida pelo Node.js.

## Comece em 3 minutos

1. Baixe a branch `formacao-code-codevibe` deste repositório (Code → Download ZIP) e extraia o ZIP em uma pasta **fora do ZeloPDV**.
2. Abra a pasta `formacao-code-codevibe` no VS Code: **Arquivo → Abrir Pasta**.
3. Abra `index.html` no navegador com dois cliques. É um livro local: não precisa de servidor, login ou dependências.
4. Leia um capítulo, responda à revisão na própria página e resolva a função correspondente em `exercicios.js`.
5. No terminal do VS Code, rode `node avaliar.cjs treino` para conferir os exercícios com retorno imediato.
6. Depois dos 10 capítulos, responda à prova objetiva em `prova.js`, complete as 5 funções finais em `exercicios.js` e execute `node avaliar.cjs prova`.
7. Com ao menos **8 de 10 questões** e **4 de 5 desafios de programação**, o script cria `certificado.html`. Abra no navegador e use **Imprimir → Salvar como PDF**.

Requer Node.js recente (18+ recomendado). Confira com `node -v`. Não é necessário `npm install`. Os dados e a evolução do livro ficam apenas no seu computador (`localStorage` do navegador). O certificado é de conclusão local e não equivale a credencial acadêmica ou profissional.

## Estrutura

- `index.html`: livro, navegação por capítulos, glossário, quizzes com feedback e referências.
- `exercicios.js`: dez desafios para treino e cinco funções para a prova prática.
- `prova.js`: respostas objetivas e nome para o certificado.
- `avaliar.cjs`: correção automática, dicas e geração do certificado.

## Programa

1. Terminal, diretórios e VS Code
2. Internet, cliente, servidor e HTTP
3. HTML, CSS, DOM e acessibilidade
4. JavaScript: variáveis, funções, objetos e arrays
5. Git, GitHub, branch e pull request
6. Node.js, npm e módulos
7. APIs, JSON, assincronismo e erros
8. Bancos de dados, SQL e modelagem
9. Testes, depuração e segurança
10. IA, agentes, prompt, contexto, RAG e entrega

Os cenários usam tickets de suporte fictícios. Todo o material é independente dos sistemas de produção.

## Critérios e limites

- Quizzes dos capítulos são formativos e podem ser repetidos; o progresso fica no navegador.
- A prova final roda localmente no VS Code. O avaliador contém os resultados esperados, como qualquer teste automatizado de um projeto local.
- Para um certificado verificável por terceiros seria preciso identidade, armazenamento externo e fiscalização. Este projeto emite apenas comprovante pessoal de conclusão.
- A página do glossário que motivou o curso não respondeu à consulta automática em 30/09/2026; esta trilha usa fontes oficiais e não afirma replicar cada verbete daquele site.
