Como estudar

  1. Leia cada capítulo e observe o exemplo.
  2. Resolva as duas perguntas de revisão clicando nas opções.
  3. Abra exercicios.js no VS Code e implemente a função do capítulo.
  4. Rode node avaliar.cjs treino no terminal; corrija o que falhar.
  5. Depois dos dez capítulos, responda prova.js e rode node avaliar.cjs prova.

O livro abre com duplo clique em index.html. O Node é necessário apenas para corrigir os códigos e emitir o certificado.
